# ECHOES OF DAWN — 夜明けの残響

**架空のファンタジーSRPG 公式サイト制作プロジェクト**

失われゆく光の謎を追い、夜に覆われつつある世界を旅する――。

『ECHOES OF DAWN（夜明けの残響）』は、世界観やキャラクター、ゲームシステムを紹介する架空のファンタジーシミュレーションRPGです。

本プロジェクトでは、ゲームの公式サイトを想定し、作品独自の世界観を伝えるWebサイトを制作しました。

## 🌙 About the Project

- **作品名：** ECHOES OF DAWN — 夜明けの残響
- **ジャンル：** ファンタジー・シミュレーションRPG（SRPG）
- **制作物：** ゲーム公式サイト
- **サイト構成：**
  - TOP — メインビジュアル・作品紹介
  - WORLD & STORY — 世界観・歴史・ストーリー
  - CHARACTERS — 登場キャラクター紹介
  - SYSTEM — 戦闘・探索・育成などのゲームシステム紹介

## 🎨 Design Concept

夜に包まれた幻想的な世界を表現するため、濃紺を基調に、星霜のブルーや植物のグリーン、月光を思わせるゴールドをアクセントとして使用しました。

落ち着いた雰囲気を保ちながら、魔法や古代文明の神秘性を感じられるデザインを目指しています。

また、キャラクターの立ち絵やゲーム画面風のビジュアルを取り入れ、実際に発売されているゲームの公式サイトをイメージして構成しました。

## ⚔️ Contents

### WORLD & STORY
夜に覆われつつある世界と、古代文明にまつわる謎を紹介します。物語の核心を明かしすぎず、作品への興味を引き出す構成を意識しました。

### CHARACTERS
個性豊かな登場人物のプロフィールや特徴を紹介します。キャラクターアイコンから詳細へ移動できる構成を取り入れ、情報を探しやすくしています。

### SYSTEM
戦闘、探索、仲間との出会い、育成や装備など、SRPGならではのゲーム要素をビジュアルとともに紹介します。
